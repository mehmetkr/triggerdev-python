# triggerdev

The first fully typed async Python SDK for the [Trigger.dev](https://trigger.dev) management API.

> **Status:** Under development. Not yet published to PyPI.

## Features (planned)

- Fully typed with Pydantic models generated from the OpenAPI spec
- Sync and async clients via httpx
- SSE streaming with reconnection for session channels
- AI agent tool definitions (LangChain/LangGraph compatible)
- Passes mypy --strict and pyright strict mode

## Requirements

- Python 3.10+
