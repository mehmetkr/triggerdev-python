# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |

Only the latest published version receives security fixes.

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

To report a vulnerability, use [GitHub's private vulnerability reporting](https://github.com/mehmetkr/triggerdev-python/security/advisories/new).

You will receive a response within 72 hours. If the report is accepted, a fix will be developed privately and released as a patch version.

## Scope

This policy covers the `triggerdev` Python package. For vulnerabilities in the Trigger.dev platform itself, report directly to [Trigger.dev](https://trigger.dev).
